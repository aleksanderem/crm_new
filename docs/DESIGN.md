# Design

Design knowledge in this repository is split between stable beliefs, implementation-specific design docs, and module context.

Stable cross-cutting beliefs live in `docs/design-docs/core-beliefs.md`.

Browsable design notes and architecture writeups live in `docs/design-docs/index.md`.

Module-specific context continues to live in `docs/modules/`.

Legacy design materials already present in the repo should be treated as inputs to this system and migrated over time, not rewritten for the sake of rewriting. Important current examples include `docs/document-templates-system.md` and the platform architecture notes under `docs/plans/`.
