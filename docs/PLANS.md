# Plans

Execution plans are stored under `docs/exec-plans/`.

Put currently active implementation plans in `docs/exec-plans/active/`.

Move finished plans to `docs/exec-plans/completed/` once the work is landed or intentionally closed.

Track durable follow-up debt in `docs/exec-plans/tech-debt-tracker.md` instead of burying it inside closed plans.

Legacy plans under `docs/plans/` remain useful history. New planning work should prefer the `docs/exec-plans/` structure and link older material where relevant.
